## 用户故事与测试 *(强制)*

### US1 (P1) 三模式对照评测
- `npm run eval` 一条命令:同一数据集跑 A(直接关键词检索)/ B(+查询改写)/ C(完整 Agent 循环),输出 recall@5、MRR、平均工具调用数、平均 token、平均延迟,产出 JSON + Markdown 双格式报告(eval/report/)。
- Independent Test: 报告文件生成且含三行模式对比表。

### US2 (P1) 指标计算正确
- recall@5 = 期望会话键出现在前 5 命中的比例;MRR = 平均倒数排名;全部由 metrics.ts 纯函数计算并有单测(构造已知命中序列断言)。

### US3 (P2) 诚实原则
- C 模式在各维度的真实表现(含劣势,如延迟/成本)照实入表;无命中类问题的诚实应答单独统计;PROJECT-RECAP 记录全部 ADR 与实测数据。
